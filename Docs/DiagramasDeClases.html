2. Datos, estado global y guardado

GameData tiene las tablas de balance. GameManager (autoload) guarda el estado de la partida. SaveManager lo escribe en JSON.

classDiagram
  direction LR
  class GameManager {
    <<Autoload>>
    +GameManager Instance$
    +GameStats Stats
    +SaveData PendingLoad
    +int CurrentScrap
    +int CurrentDay
    +int CurrentRound
    +GameState CurrentState
    +Perks
    +StartNewGame()
    +RestoreFromSave(SaveData)
    +AddScrap(int)
    +AddScrapFromKill(int) int
    +SpendScrap(int) bool
    +StealAllScrap() int
    +SetDay(int, int)
    +SetState(GameState)
    +Radio(string, RadioKind)
    +AddPerk(PerkType)
    +NotifyBossDefeated()
    +TriggerGameOver()
    +GetUnitCost(UnitType) int
    +multiplicadores de perks
  }
  class GameData {
    <<static>>
    +Units
    +Enemies
    +Structures
    +Perks
    +DayHealthMultiplier(int)$
    +DayDamageMultiplier(int)$
  }
  class GameStats {
    +Kills
    +BossesKilled
    +ScrapEarned / Spent / Stolen
    +UnitsRecruited / Lost
    +StructuresBuilt / Lost
    +DamageDealt
    +TimePlayed
    +AddKill(EnemyType)
  }
  class SaveManager {
    <<static>>
    +Save(Main) bool
    +Load() SaveData
    +DeleteSave()
    +LoadRecords() RecordsData
    +UpdateRecords(GameStats)
  }
  class SaveData {
    +Day
    +Scrap
    +BaseHealth
    +Perks
    +Stats
    +Units: List~UnitSave~
    +Structures: List~StructureSave~
  }
  GameManager *-- GameStats
  GameManager ..> GameData : lee costos y perks
  GameManager ..> SaveManager : al morir borra y guarda récords
  SaveManager ..> SaveData
  SaveData *-- GameStats
  GameData *-- UnitStats
  GameData *-- EnemyStats
  GameData *-- StructureStats
  GameData *-- PerkInfo

3. Unidades, escuadras y combate

Hay un solo Soldier configurable en 5 tipos. SquadManager implementa los escuadrones orgánicos del GDD.

  Soldier *-- Health
  Soldier *-- Move
  Base *-- Health
  SquadManager o-- Soldier : escuadras 1-4
  Soldier ..> Base : se cura y recupera moral
  Soldier ..> Combat
  Soldier ..> Effects : disparos
  • Líder ★: da +10% de daño a los miembros cercanos. Si muere, asume el de más vida y la escuadra queda sin moral ▼ (−25% de daño) hasta curarse en la base.
  • Torre: hasta 2 soldados arriba, con +40% de alcance y la mitad del daño recibido.

7. Ciclo de juego

stateDiagram-v2
  [*] --> Menu
  Menu --> Oleada1 : Jugar (partida nueva)
  Menu --> EntreDias : Cargar (partida guardada)
  Oleada1 : Combate · Oleada 1
  Espera : Combate · 20 s (N adelanta)
  Oleada2 : Combate · Oleada 2 (jefe cada 5 días)
  Perk : Pausa · elegir 1 de 3 perks
  EntreDias : Entre días · autoguardado
  GameOver : Estadísticas + perks
  Oleada1 --> Espera : sin enemigos
  Espera --> Oleada2
  Oleada2 --> Perk : jefe abatido
  Perk --> Oleada2
  Oleada2 --> EntreDias : sin enemigos
  EntreDias --> Oleada1 : Pasar de día (Enter)
  Oleada1 --> GameOver : base destruida
  Oleada2 --> GameOver : base destruida
  GameOver --> Oleada1 : Nueva partida
  GameOver --> Menu : Menú principal
